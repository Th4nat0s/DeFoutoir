# Agent Instructions

- The project must use a logger system to report what is happening.
- Logger messages must be printed clearly for important actions, progress, warnings, and errors.
- Black and Pylint are mandatory.
- All code must be documented in simple English.
- Documentation must include clear usage examples.
- Every code change must include or update tests.
- The code must support Python 3.10.
- Every operation must print a clear status message.
- Quality and score must never regress. New changes must keep or improve the current quality and score.
